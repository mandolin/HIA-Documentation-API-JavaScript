## Publication

`snapshot.json` pins the source commit, publication identity, registry and complete archive digests. GitHub Actions verifies every archived file and the native documentation, source maps, public bindings and full-source downloads before deploying GitHub Pages.

Generated files are supplied through the pinned release archive. To update the content, build the source repository, validate the two sites, publish the fixed archive and update the snapshot manifest. Each deployment retains explicit locale and system-documentation version targets.
